# Vidro website

The existing Next.js website now presents the editor. Page order is hero with a live editor showcase and a logo-and-name framework/library carousel, playground, pricing, footer. The centered header badges highlight the native `<vidro-editor>` Web Component; the carousel uses locally licensed Devicon marks beside frontend names. The Vidro logo, IBM Plex fonts, cracked-glass hero, shared visual tokens, and four marketing locales are retained.

The locale pill expands on hover or click. Language links navigate to `/en/`, `/pt-BR/`, `/zh/`, and `/ja/`, preserving query strings and section hashes. Next.js Proxy redirects `/` to the preferred locale from the cookie or `Accept-Language` header, and visiting a locale route updates the cookie. The route renders the corresponding translation and HTML `lang` on the server.

SEO follows the [LangDrift metadata structure](https://github.com/jonatassales/langdrift/tree/59355f9199664dcd16af2aa13c70f22513e191b3/spaces/apps/website/src/app/metadata): site, locale, page, and organization JSON files plus a shared page-metadata helper in `app/metadata/`. All four home pages have server-rendered localized titles/descriptions, self-canonical URLs, language alternates including `x-default`, Open Graph and Twitter cards. Native Next.js routes generate branded 1200×630 PNG sharing images, a 180px Apple icon, `/manifest.webmanifest`, `/robots.txt`, and `/sitemap.xml`. The sitemap lists the four localized home pages and `/license/` and `/policies/`; pending `/terms/`, `/privacy/`, and `/third-party/` pages stay noindex with followable links. Embedded hero/playground responses carry `X-Robots-Tag: noindex` so their standalone documents do not compete with the landing page. Home JSON-LD describes Neongate, the website, and the Vidro application with its proprietary license link. No purchasable offer is advertised in structured data while checkout is disabled. `NEXT_PUBLIC_SITE_URL` can override the default `https://vidro.pro` origin consistently across metadata and discovery routes.

The embedded playground starts in dark mode, with a working light/dark toggle. It omits source/file-input and event-log panels; its shared property controls and all four editors remain available. Typography and Frame & layout start collapsed. Developer source and event controls remain in the standalone sandbox, which starts light. The website shows no version-preview badge.

The footer keeps the Vidro description aligned at the left, links to `/license/` and `/policies/`, and presents five vertical icon-and-name links under “Backed by:”. The Monaco link uses Microsoft's mark. Neongate's native `<orb-z>` Web Component appears beside its copyright in the bottom row; all footer icons are 18px. Social icons turn from grey to their accent color on hover or keyboard focus and use local hash targets until real destinations are provided. See [footer icon sources](public/backed-by/SOURCES.md).

`/license/` renders the editor package’s interim proprietary notice, not a final commercial EULA. `/policies/` is the legal-document index. `/terms/`, `/privacy/`, and `/third-party/` contain only owner-provided pending-publication text, with shared legal navigation. The former misspelled route is removed without a compatibility redirect. Monaco’s original license and notices remain separate in the editor package. This change does not retroactively revoke rights validly granted for older distributed versions.

From the repository root, run `pnpm sandbox` or `pnpm sandbox --preview`. The launcher builds `packages/editor` and shared UI before serving this app. The website build generates `/hero-editor/index.html` and `/playground/index.html` from the public editor package and `/editor-api.md` from its README; generated files are ignored by Git.

The same-origin hero and playground frames size themselves using validated messages, keeping a single page scroll. In development, the package watcher finishes before the frames rebundle; open frames then reload automatically. The hero frame has a transparent canvas and a stable 286px editor height. Every three seconds it cycles through light default with header, dark default without header, light unified diff, light split diff, light file list, and dark editable code typing. The final scene types the first line character by character, the second word by word, then pastes the rest. The file list switches from its first disclosure to its second after 1.5 seconds. One mounted editor is configured through built public exports and its accessible disclosure buttons. SmoothUI's displacement wipe swaps scenes at its midpoint; the title and slogan use Blur Out Up with a 500ms delay.

Hero playback pauses offscreen, in a hidden tab, and during pointer or keyboard interaction. Reduced-motion and forced-colors preferences show a static first scene; unavailable WebGL falls back to direct scene changes. Shader animation frames run only during transitions and are cleaned up when the frame unloads. Playground controls remain independent.

The $1 one-time price remains consistent in all four locales, but the card always opens the playground. `NEXT_PUBLIC_VIDRO_CHECKOUT_URL` cannot enable paid checkout while Terms of Sale and applicable privacy information are pending. A payment processor is not implemented here; enabling purchases requires defined license and purchase terms, actual-data-flow privacy information, and a completed review of distributed third-party software and assets.

Pricing/footer adapt official SmoothUI sources; see [provenance and license](vendor/smoothui/README.md). Website styling uses shared Vidro tokens and Tailwind, not SmoothUI's separate token system.
